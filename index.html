User Manual

First time here?

If you have not set up DreamDexed on your Raspberry Pi yet, open the Install Guide first – it walks you through downloading the ready-to-use ZIP and copying it to the SD card. Come back here when the Pi appears as a MIDI device on your PC.

Purpose

DreamDexed / miniDexed on a Raspberry Pi is normally operated headless. Without a screen and without a keyboard attached to the Pi, you cannot browse or select performances directly on the device. This Controller provides exactly that missing user interface: connect a "bare" Raspberry Pi running in USB gadget mode to a PC, open the browser, and select performances, banks and programs, adjust master volume, and step through parameters using the PGM / BANK navigation keys – all without a monitor, a keyboard, or any extra software on the Pi itself.

No bridge, no server, no additional tooling on either side: the browser talks straight to the Pi over the Web MIDI API.

Overview

The DreamDexed Controller drives miniDexed / DreamDexed on a Raspberry Pi via the Web MIDI API. The Pi runs in USB gadget mode and appears on Windows as a MIDI interface. The controller runs in the browser (Chrome / Edge / Brave) and sends directly – no bridge, no server.

Establishing a connection

  1. Connect the Raspberry Pi to the PC via USB.
  2. In the MIDI OUT dropdown, select the device. Devices whose name contains dreamdexed, minidexed or gadget are detected automatically and pre-selected.
  3. Press CONNECT.

On first launch, the browser asks for MIDI permission (including SysEx). This must be granted, otherwise volume control will not work. The last selection is stored in the browser.

MIDI In (optional forwarding)

The Controller can also forward incoming MIDI data to the Raspberry Pi. This lets you play notes from a DAW or from a plugin such as Dexed Standalone while the Controller handles program changes at the same time.

To use this feature, the MIDI source must appear as a MIDI input that the operating system can see. The Controller does not require any special software on its side – it simply forwards whatever it receives.

  1. In the Controller, select the source in the MIDI IN dropdown. Forwarding starts automatically – choose — off — to stop it.

Forwarding is 1:1. Every incoming MIDI message is passed to the selected MIDI OUT exactly as it arrives, on its original channel. No channel is rewritten, nothing is filtered – with one exception: Active Sensing (0xFE) messages are discarded. Many older keyboards send them every ~200 ms as a "keep-alive" signal. The Pi does not need them, and some devices misbehave on them. The green activity dot next to the dropdown blinks briefly on every forwarded message.

Prog Ch

The Prog Ch selector sets the MIDI channel used for everything the Controller itself sends: Program Change, Bank Select, Master Volume (SysEx) and the PGM / BANK navigation keys. The default is 10, matching PerformanceSelectChannel=10 in DreamDexed.

Why this matters: notes forwarded from the MIDI IN usually arrive on channel 1, while program changes are sent on channel 10. Keeping them on separate channels avoids "ghost notes" – a note message being misinterpreted as a program change on the same channel.

Selecting programs

Program PPP + ENTER (1–128) Bank + Program BBB/PPP + ENTER (1–128 / 1–128)

Example: 64 + ENTER selects program 64. 3/12 + ENTER selects bank 3, program 12.

Volume

  • Slider: value 0–127.
  • Presets: 64, 100, 127.
  • MUTE: sets volume to 0 and remembers the previous value. A second click restores it.
  • Default value on startup: 64.

Navigation (right of the numpad)

PGM + / − Program up / down BANK + / − Bank up / down

These keys send Note-On (velocity 1) on press and Note-Off on release. After pressing, the green status line is cleared, because the Pi has changed its value on its own and the controller does not know the new value.

Keyboard shortcuts

As long as the browser window has focus, the Controller can be driven entirely from the PC keyboard. All shortcuts behave exactly like their on-screen counterparts, including the Note-On / Note-Off cycle and the visual highlight on the matching button.

0 – 9 Numpad digits /  or  : Bank / Program separator Enter Send the buffered program or bank/program Backspace Delete last character Escape Clear current input + PGM +  (program up) − PGM −  (program down) Page Up BANK +  (bank up) Page Down BANK −  (bank down)

Note: If a dropdown currently has keyboard focus (after clicking a select), plain character shortcuts are suppressed so that the dropdown's own key handling is not disturbed. Click anywhere on the panel to return focus to the Controller.

Performance List (Perflist.pdf)

The PERFLIST.PDF button in the top-right corner opens the Performance List that ships with this project – a modified edition of the Soundplantage list. When the PDF is open, the Controller shifts to the left so that both fit on screen. Click the button again or use the ✕ in the PDF header to close it.

Bank 1 contains a hand-picked selection of favourites chosen for this project – a good place to start exploring. Banks 2 and up are the original Soundplantage banks, unchanged.

The PDF is loaded from the same folder as the Controller. When you use the online version (GitHub Pages), it works immediately. When you open the Controller locally from a downloaded copy, keep the PDF next to index.html – then no internet connection is needed.

Numpad

  • Mouse: click the keys.
  • Keyboard: see Keyboard shortcuts above.

Displays

  • Green LCD (left): current input (right-aligned) and, below it, the last command that was sent.
  • Blue OLED (right): log of the last 5 MIDI commands. New entries appear at the bottom, older ones drop off the top. Forwarded notes are not logged, to keep the program-change history readable.

Troubleshooting

  • no MIDI output selected – no output chosen. Check that the Pi is connected, then press CONNECT.
  • Web MIDI API not available – the browser does not support Web MIDI. Use Chrome, Edge or Brave.
  • MIDI access denied – permission was denied in the browser. Reset it in the site settings and reload.
  • Volume does not respond – SysEx permission is missing. The MIDI permission dialog (including SysEx) must be accepted when connecting.
  • Notes are not forwarded – check the MIDI IN dropdown.
  • PERFLIST.PDF shows nothing – make sure the file Performance List.pdf sits next to index.html. Some browsers block local file embeds; if you opened the Controller directly from your file system, use the online version instead.
