User Manual

About this manual

This manual covers operating the Controller – how to select sounds, adjust volume, and drive everything from the mouse or the PC keyboard. Setting up the Raspberry Pi and installing DreamDexed is covered in the Install Guide.

First look – the two displays

  • Green LCD (left): shows what you are typing (right-aligned) and, below it, the last command that was sent to the Pi.
  • Blue OLED (right): a running log of the last five MIDI messages. Useful to confirm that a command actually went out. Forwarded notes are not logged – the log stays focused on the commands you send.

Connecting the Pi

Select the Raspberry Pi in the MIDI OUT dropdown. The connection is established immediately. The OLED log confirms with >> connected to …. Your selection is remembered for the next time.

If you want to play notes from your MIDI keyboard through the Pi, select the keyboard in the MIDI IN dropdown. Forwarding starts automatically – choose — off — to stop it. The small dot next to the dropdown blinks whenever incoming MIDI data arrives.

Selecting a sound – the syntax

This is where most of the work happens. Every performance on the Pi has a bank and a program number. You type them on the numpad and press ENTER.

Program only PPP + ENTER  (1–128) Bank + Program BBB/PPP + ENTER  (1–128 / 1–128)

Examples

  • 64 + ENTER → program 64 in the current bank
  • 2/87 + ENTER → bank 2, program 87
  • 3/12 + ENTER → bank 3, program 12

Typing mistakes

  • Backspace – deletes the last digit
  • ESC – clears the whole input
  • A number outside 1–128 shows an error on the LCD and clears the input automatically.

Quick Select

The Quick Select button opens a browsable list of all performances, grouped by bank. It reads perflist.js next to index.html. This file is produced by perfscan.html and works directly from disk as well as from a web server.

  • Bank tabs across the top switch between the banks found in the performance list (e.g. 001 Seed, 002 Greenhouse, …).
  • The title bar shows the currently visible bank, formatted as BBB – BankName.
  • Performances are laid out column by column: program 1–32 in the first column, 33–64 in the second, and so on. With a full bank that is four columns of 32 rows.
  • A double-click on a cell sends a Bank Select and a Program Change on the current Prog Ch – the performance is loaded on the Pi right away.
  • The performance currently loaded is highlighted with a green frame. Long names are truncated with …; hover to see the full name in a tooltip.

If the performance list cannot be loaded at all, Quick Select shows a short hint instead of the list. Make sure perflist.js sits next to index.html.

Stepping through banks and programs

PGM + / − Program up / down BANK + / − Bank up / down

Each press sends a short MIDI message to the Pi, which advances to the next or previous program. The LCD status line is cleared after each press, because from that moment on the Pi is the source of truth for what is selected.

Volume

  • Slider: value 0–127.
  • Presets: 64, 100, 127.
  • MUTE: sets volume to 0 and remembers the previous level. A second click restores it.

The Performance List (Perflist.pdf)

The PERFLIST.PDF button opens the printed Performance List alongside the Controller. It is your reference for the sound names as originally supplied.

Typing on the PC keyboard

Everything you can do with the mouse, you can do with the PC keyboard. As long as the browser window has focus, the Controller listens to:

0 – 9 Numpad digits /  or  : Bank / Program separator Enter Send the buffered input Backspace Delete last character Escape Clear current input / close dialogs + PGM +  (program up) − PGM −  (program down) Page Up BANK +  (bank up) Page Down BANK −  (bank down)

So if you want to select bank 2, program 87, just type 2/87 and press Enter – no need to touch the mouse. Digits and the separator appear immediately on the green LCD, so you always see what will be sent. The PGM and BANK buttons light up briefly while their keyboard shortcuts are held down.

Tip: If a dropdown currently has keyboard focus (after you clicked it), plain character shortcuts are suppressed so that the dropdown's own key handling is not disturbed. Click anywhere on the panel to return focus to the Controller.

Clearing an error

If the green LCD shows ERROR: expected PPP or BBB/PPP, the number you typed was empty, contained non-digits, or fell outside the 1–128 range. Press ESC or Backspace to clear the input and try again. Any further digit clears the message automatically.

If something does not work

  • no MIDI output selected – no output chosen. Check that the Pi is connected, then pick it in the MIDI OUT dropdown.
  • Volume does not respond – the browser's MIDI permission (including SysEx) was not granted. Reset it in the site settings and reload.
  • Notes from the keyboard are not heard – check the MIDI IN dropdown.
  • PERFLIST.PDF shows nothing – the PDF must sit next to index.html. Some browsers block local file embeds; use the online version instead.
  • Quick Select shows "could not load performance list" – make sure perflist.js sits next to index.html.
  • Other errors – the Install Guide's troubleshooting section covers the setup side.
