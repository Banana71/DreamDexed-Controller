Read this before connecting power

This project is written for the Raspberry Pi 4. In USB Gadget Mode, the Pi uses its USB-C port for both data and power – the same cable that connects it to your PC.

  • Do NOT connect a separate power supply while the Pi is in Gadget Mode.
  • The Pi must be USB bus powered only – this is required by the USB specification.
  • Use the USB-C port (the one you would normally plug the power supply into).
  • Never use the blue USB-A ports for Gadget Mode – those are host ports only.
  • If you need the Pi to be powered independently (for example, to add a display later), use a USB-C Power / Data Splitter. Do not improvise this.

The official MiniDexed Wiki puts it plainly: “When using a Raspberry Pi in USB Gadget mode, do not plug in its usual power supply! It should be USB 'bus powered' only.”

01 What is DreamDexed?

DreamDexed is a project that runs MiniDexed – a faithful software emulation of the legendary Yamaha DX7 – on a Raspberry Pi. It turns a small, inexpensive computer into a multi-timbral 6-operator FM synthesizer with eight tone generators, built around the original DX7 engine.

Normally DreamDexed runs headless: no screen, no mouse, no keyboard attached to the Pi. All communication happens over MIDI – either from a hardware controller or, as in this project, from a PC.

The DreamDexed Controller is exactly that missing user interface. It runs entirely in your browser (Chrome, Edge or Brave), talks directly to the Raspberry Pi over the Web MIDI API, and lets you select performances, adjust volume and step through banks and programs – no extra software, no bridge, no server. The Pi simply appears on your PC as a MIDI device, and the browser speaks to it.

The Performance List shipped with this project contains a curated collection of sounds prepared by Soundplantage. To hear them, you need a MIDI keyboard or controller connected to your PC – MiniDexed only produces sound when note messages arrive. Once the keyboard is set up in the Controller's MIDI IN dropdown, playing a key immediately plays the currently selected performance on the Pi.

02 What you need

The bare minimum to get the first sound out of DreamDexed is deliberately short. A DAC, an OLED display or a rotary encoder are not required to get started – they improve the experience, but you can add them later.

Qty Part Notes
1 Raspberry Pi 4 The smallest memory variant (1 GB) is more than enough.
1 USB-C to USB-A cable Used to connect the Pi 4 to the PC and to power it in Gadget Mode.
1 SD card 8 GB or larger, Class 10 recommended.
1 PC with browser Chrome, Edge or Brave. The Controller needs the Web MIDI API.
1 MIDI keyboard or controller Any USB MIDI keyboard. Must be able to send on MIDI channel 1 – all performances are configured to listen on channel 1.
0–1 MIDI-to-USB adapter Only needed if your keyboard has a 5-pin DIN output. USB MIDI keyboards connect directly.
1 Headphones or speakers Plugged into the Pi's 3.5 mm jack (PWM output). See section 06 for sound quality.

Optional, but worth knowing about: a PCM5102A DAC HAT (under €10) dramatically improves the sound, an SSD1306 OLED display shows the current performance directly on the Pi, and a KY-040 rotary encoder allows hardware navigation. More on that in section 08.

03 Quick start – step by step

Follow these steps in order. The whole procedure takes about 15 minutes the first time, mostly waiting for the SD card.

  1. Download DreamDexed. Grab the current build from the DreamDexed project (link below). The file is a ZIP archive containing the ready-to-flash system.
    ⬇ Download DreamDexed (build 261)

    This is a snapshot of the DreamDexed continuous release. If the link ever stops working, check the DreamDexed Releases page for the current build.

  2. Write the image to the SD card. Use Raspberry Pi Imager, balenaEtcher or a similar tool. Select the downloaded ZIP file as the source and your SD card as the target.
  3. Replace the minidexed.ini on the SD card. After flashing, open the SD card on your PC (the first partition is readable on Windows and macOS). Replace the existing minidexed.ini with the one provided with this project (download link below), or edit the five parameters listed in section 04 by hand.
    ⬇ Download minidexed.ini
  4. Insert the SD card into the Pi and connect the Pi to your PC using the USB-C cable. Remember the warning at the top of this page: use the USB-C port, and do not connect any other power supply.
  5. Wait about 15 seconds. The Pi boots and identifies itself to the PC as a MIDI device named DreamDexed or Gadget Serial.
  6. Open the Controller. Click the red Go to Controller button at the bottom of this page, select the Pi in the MIDI OUT dropdown, and press CONNECT.
  7. Plug in headphones at the Pi's 3.5 mm jack. Set the volume slider in the Controller to something comfortable.
  8. Connect your MIDI keyboard to the PC (USB) and switch it on. In the Controller, open the MIDI IN dropdown and select your keyboard. The green activity dot next to the dropdown should blink when you press a key. Set the keyboard to send on MIDI channel 1 – all performances listen on channel 1.
  9. Play a performance. Type a number between 1 and 128 on the keypad and press ENTER. The Pi switches to that performance. Now play a note on your keyboard – you will hear the selected sound. Look at the Soundplantage Performance List (the PERFLIST.PDF button in the Controller) to see which number corresponds to which sound.
04 The minidexed.ini – five key lines

The minidexed.ini file on the SD card controls how the Pi behaves. Five lines are essential for the Controller to work. If you replace the whole file with the one provided here, they are already set correctly. If you prefer to edit your own file, look for these entries and change them: 

# USB Gadget Mode: 1 = device mode (Pi appears as a MIDI interface on the PC)
USBGadget=1

# Enable Program Change reception (needed for performance selection)
MIDIRXProgramChange=1

# Program Changes on MIDI channel 10 select performances
PerformanceSelectChannel=10

# MIDI button navigation: navigation buttons are sent as Note messages
MIDIButtonCh=10
MIDIButtonNotes=1

What each line does

Parameter Purpose
USBGadget=1 Enables USB Gadget (device) mode. The Pi identifies itself to the PC as a MIDI device. Without this, the PC cannot see the Pi, and the Controller has nothing to talk to.
MIDIRXProgramChange=1 Tells MiniDexed to respond to Program Change messages. If this is 0, sending a program number from the Controller has no effect.
PerformanceSelectChannel=10 Program Changes arriving on MIDI channel 10 select performances rather than individual voices. This is the channel the Controller sends on by default.
MIDIButtonCh=10 The MIDI channel on which MiniDexed listens for navigation button messages. The Controller sends the PGM and BANK keys on this channel.
MIDIButtonNotes=1 Treat the button numbers below as MIDI Note numbers triggered by Note On / Note Off, rather than as Control Change numbers. The Controller uses this mode.

Additional lines from the file (unchanged from default)

The full default file also contains definitions for the individual navigation buttons. These lines map each button to a MIDI Note number and an action. They are already correct in the file provided with this project: 

# Arrow left
MIDIButtonPrev=1          MIDIButtonActionPrev=click
# Arrow right
MIDIButtonNext=2          MIDIButtonActionNext=click
# Arrow up
MIDIButtonBack=3          MIDIButtonActionBack=click
# Arrow down
MIDIButtonSelect=4        MIDIButtonActionSelect=click
# Home button
MIDIButtonHome=5          MIDIButtonActionHome=click
# PGM / BANK / TG
MIDIButtonPgmUp=6         MIDIButtonActionPgmUp=click
MIDIButtonPgmDown=7       MIDIButtonActionPgmDown=click
MIDIButtonBankUp=8        MIDIButtonActionBankUp=click
MIDIButtonBankDown=9      MIDIButtonActionBankDown=click
MIDIButtonTGUp=10          MIDIButtonActionTGUp=click
MIDIButtonTGDown=11        MIDIButtonActionTGDown=click

Full reference: MiniDexed Wiki → MIDI Button Navigation

05 Your first session with the Controller

Once the Pi is connected and the Controller shows connected in the log, everything is driven from this page.

Selecting a performance

  • Single performance: type a number from 1 to 128 on the keypad and press ENTER. That performance starts immediately.
  • Bank + Performance: type the bank, then /, then the performance number – for example 3/12 – and press ENTER.
  • Wrong digits? Press ESC to clear the input, or Backspace to remove one character.

Playing notes with a MIDI keyboard

MiniDexed is a synthesizer – it only makes sound when note messages arrive. There is no built-in demo playback. To hear a performance you need a MIDI keyboard connected to your PC, and its output must reach the Pi through the Controller.

  1. Connect the MIDI keyboard to your PC (USB) and switch it on.
  2. In the Controller, open the MIDI IN dropdown and select your keyboard. Forwarding starts automatically – choose — off — to stop it.
  3. The green activity dot next to the dropdown blinks briefly on every incoming message. If it does not blink when you press a key, the keyboard is not sending, or it is on a port the browser cannot see.
  4. Check that your keyboard sends on MIDI channel 1. All performances in the Soundplantage Performance List listen on channel 1. Most keyboards have a global channel setting – usually in a menu called MIDI Channel, Transmit Channel or similar.
  5. Play a few notes. You should hear them through the Pi's audio output. Active Sensing messages (0xFE) sent by some older keyboards are filtered out automatically and do not disturb the forwarding.

Note: The Controller forwards MIDI data 1:1 – whatever your keyboard sends arrives at the Pi unchanged, on the same channel. The only filtering is Active Sensing. Program Change, bank selection, volume and the PGM / BANK keys are sent by the Controller itself on a different channel (default 10), so they never interfere with the notes you are playing.

Adjusting volume

  • Move the Volume slider. Presets 64, 100 and 127 are provided.
  • MUTE sets volume to 0 and remembers the previous value – a second click restores it.

Stepping through performances

  • PGM + / − moves one performance up or down.
  • BANK + / − switches the bank.
  • These are MIDI Note messages, defined in the minidexed.ini file. You can also trigger them from the PC keyboard: +, −, Page Up, Page Down.

Reading the displays

  • Green LCD: your current input (right-aligned) and, below it, the last command the Controller sent to the Pi.
  • Blue OLED: the last five MIDI messages in hexadecimal form. Useful for troubleshooting.

Playing the Performance List

Click PERFLIST.PDF in the top-right corner of the Controller to open the Soundplantage Performance List alongside the interface. It shows which number corresponds to which performance.

06 Sound quality – an honest word

Without an external DAC, the Pi uses its built-in PWM output to drive the 3.5 mm jack. On a Raspberry Pi 4 this is a simple digital-to-analog converter built from a filtered square wave – and it sounds like it.

  • You will hear a constant hissing background.
  • Depending on the Pi and the load, there may be a quiet high-frequency whine.
  • Dynamic range and stereo separation are modest.
  • It is fine for learning the interface and hearing which performance does what – but not for serious listening or recording.

The good news: a small PCM5102A DAC HAT costs under €10, plugs onto the Pi's GPIO header, and gives you a real I²S DAC with clean 32-bit / 384 kHz output. The difference is not subtle – it is the difference between “a toy that makes FM sounds” and “a proper synthesizer”.

Enabling a DAC requires a small change to the minidexed.ini file (SoundDevice=i2s instead of SoundDevice=pwm) and a configuration change in the Pi's config.txt. The MiniDexed Wiki covers this in detail, and the whole procedure takes about five minutes.

For now: get the first sound out, get comfortable with the interface, and consider a DAC as the natural next upgrade.

07 Troubleshooting

No sound when playing the keyboard

  • Check that the MIDI IN dropdown in the Controller shows your keyboard and not — off —.
  • Check that the green activity dot next to the dropdown blinks when you press a key. If not, the keyboard is not reaching the browser.
  • Check the keyboard's MIDI transmit channel – it must be channel 1. All performances listen on channel 1.
  • Check the Prog Ch selector – it should be 10 (or whatever your minidexed.ini uses) and is independent of the keyboard channel.
  • Check the volume slider in the Controller and MasterVolume in the INI.

The keyboard is not visible in the MIDI IN dropdown

  • Reconnect the keyboard and reload the page.
  • On Windows: open Device Manager and check that the keyboard appears under Sound, video and game controllers.
  • If your keyboard has a 5-pin DIN output, you need a MIDI-to-USB adapter. USB MIDI keyboards connect directly.
  • Some keyboards need a driver or a mode switch (e.g. from MIDI to USB) before they appear as a MIDI device.

The Controller does not see the Pi

  • Check the USB cable – use the USB-C port on the Pi 4.
  • Check that USBGadget=1 is set in the minidexed.ini.
  • Unplug and replug the USB-C cable, then reload the Controller page.
  • On Windows: open Device Manager and look for a device named DreamDexed or Gadget Serial.

No sound at all

  • Check the volume slider in the Controller.
  • Check that headphones are plugged fully into the Pi's 3.5 mm jack.
  • Check MasterVolume in the minidexed.ini – the default is 64.
  • Try a different performance number – some performances might be quieter than others.

Program change has no effect

  • Check MIDIRXProgramChange=1 in the minidexed.ini.
  • Check PerformanceSelectChannel=10.
  • Make sure the Prog Ch selector in the Controller is set to 10.

The PGM and BANK buttons do nothing

  • Check MIDIButtonCh=10 in the minidexed.ini.
  • Check MIDIButtonNotes=1.
  • Check that the button mappings (MIDIButtonPgmUp=6, etc.) are present.

PERFLIST.PDF shows nothing

  • Check the internet connection. The list is loaded from an online mirror.
  • Try reloading the page.
08 Next steps

Once you have the basic setup running, there are several ways to take it further. None of them are required – they simply add polish.

  • Add a DAC. A PCM5102A HAT plugs onto the GPIO header and transforms the sound quality. Under €10.
  • Add an OLED display. A small SSD1306 (128×64) shows the current performance directly on the Pi. Configured via SSD1306LCDI2CAddress in the INI file.
  • Add a rotary encoder. A KY-040 lets you step through performances without the PC. Configured via EncoderEnabled, EncoderPinClock and EncoderPinData.
  • Create your own performances. DreamDexed uses the standard DX7 SysEx format. Any DX7 patch editor can be used to craft new sounds.

The full reference documentation lives on the MiniDexed Wiki: github.com/probonopd/MiniDexed/wiki. Project-specific questions and DreamDexed builds are at github.com/DreamDexed/DreamDexed.
