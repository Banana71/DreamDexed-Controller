Build perflist.js from your SD card · by SOUNDPLANTAGE.COM
What this does

Point this tool at your SD card. It finds the performance/ folder, scans every bank folder, and writes one file next to index.html:

perflist.js – loaded directly by the Controller. Works even when index.html is opened from disk (file://), no local server needed.

The file contains two sections: banks with number and name, and performances with one line per performance, e.g. "004, 012, Legend'83".

Set an output folder once and every subsequent save lands there directly – no dialog. Nothing is uploaded.

Output (not set – Save As dialog)
